# Remove Electrum

Foundry VTT 13 ve D&D 5e için Electrum (ep) para birimini oyundan kaldırır. Karakter sayfalarında, eşya fiyatlarında ve para birimi listelerinde yalnızca pp, gp, sp ve cp görünür.

## Kullanım

Modülü etkinleştirmeniz yeterli; ayarı yoktur.

## Not

Modül etkinleştirilmeden önce karakterlerin cüzdanında bulunan Electrum değerleri silinmez, yalnızca görünmez olur. Gerekirse etkinleştirmeden önce elektrumu gp veya sp'ye çevirin (1 ep = 5 sp).

## Gereksinimler

- Foundry Virtual Tabletop 13 (13.351 ile doğrulandı)
- dnd5e
